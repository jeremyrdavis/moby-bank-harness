# Product Mission

## Problem

Teams that want to give their employees an AI agent need a custom harness (a chat UI and backend) that talks to an agent running in Docker Sandboxes, both locally and in the cloud. There is no reference showing how to build one.

## Target Users

Engineering and platform teams building a custom agent harness for their organization, who will reuse this demo's pattern. (The demo frames this around a fictional bank credit analyst, but the audience evaluating it is the engineering team.)

## Solution

The same agent, local or cloud. One harness drives a Docker Sandbox running on the user's machine or in the cloud, and a session can move between the two.
