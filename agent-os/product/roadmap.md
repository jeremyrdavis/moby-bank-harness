# Product Roadmap

## Phase 1: MVP

- Chat UI with agent traces (prototype built; agent behavior currently simulated client-side)
- Real local sandbox backend: the harness connects to an agent running in a Docker Sandbox on the user's machine
- Real cloud sandbox backend: the harness connects to an agent running in a cloud Docker Sandbox
- Move session local → cloud
- Move session cloud → local
- Integration with Microsoft OneDrive

Backend delivery: two implementations of the backend, built sequentially, one in Java/Quarkus and one in Python (see `tech-stack.md`).
